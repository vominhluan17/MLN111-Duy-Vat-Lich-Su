# 🏛️ Triết Học Mác-Lênin | Biện Chứng Cơ Sở & Thượng Tầng

**Website thuyết trình tương tác cực kỳ hiện đại về Triết Học Mác-Lênin**

## ✨ Tính Năng Nổi Bật

- 🎬 **Cinematic Animations** - Hiệu ứng chuyển cảnh mượt như Apple website
- 📜 **Scroll Storytelling** - Câu chuyện được khai triển khi cuộn trang
- ⏱️ **Interactive Timeline** - Timeline phát triển xã hội có thể tương tác
- 🧠 **Mind Maps Động** - Sơ đồ tư duy với animation
- 🌌 **Parallax Effects** - Hiệu ứng parallax và motion backgrounds
- 🤖 **AI Chatbot** - Chatbot hỗ trợ giải thích bài học
- 📱 **Fully Responsive** - Hoạt động hoàn hảo trên laptop và mobile
- 🌙 **Dark Mode Akademic** - Giao diện dark mode hiện đại

## 🛠️ Tech Stack

- **ReactJS 19** - Frontend framework
- **Vite 8** - Build tool siêu nhanh
- **TailwindCSS 3** - Utility-first CSS
- **Framer Motion** - Animation library
- **Lenis** - Smooth scroll library
- **React Icons** - Icon library

## 🚀 Cài Đặt & Chạy

### Yêu Cầu
- Node.js 16+
- npm 8+

### Cài Đặt

```bash
# Vào thư mục
cd c:\Users\gmt\triet-hoc-presentation

# Cài đặt dependencies
npm install

# Chạy development server
npm run dev
```

Mở `http://localhost:5173` trong trình duyệt

### Lệnh Khác

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```
